# Primeiros Passos com o Widget Embedded

Escolha a abordagem que melhor se adapta às suas necessidades:

### Implementação Passo a Passo

Se você deseja **integrar o Widget Embedded** diretamente na sua aplicação web existente e tem familiaridade com desenvolvimento front-end, siga nosso guia de implementação passo a passo. Este guia detalha cada etapa, desde a inclusão da biblioteca até a configuração dos callbacks.

[Acessar Guia de Implementação Passo a Passo](/v3.0/docs/implementando-o-widget-embedded)

### Exemplo Prático (Docker)

Para uma forma rápida e isolada de **experimentar o Widget Embedded**, utilize nosso código e setup com Docker. Com alguns comandos, você poderá subir um container pré-configurado e visualizar o widget em funcionamento, ideal para testes iniciais e para entender o fluxo.

[Acessar Guia do Exemplo Prático com Docker](/v3.0/docs/exemplo-pratico-com-docker)
