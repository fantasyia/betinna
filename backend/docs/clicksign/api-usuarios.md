# Usuários

**Bem-vindo à página de referência dos endpoints de Usuários da Clicksign!**

Abaixo, você encontrará uma lista detalhada de todos os endpoints disponíveis para criar e listar usuários usando nossa API. Lembrando que, os endpoints listados abaixo só ficam disponíveis para utilização por contas que possuam o login via **SSO habilitado**. Cada endpoint é acompanhado por uma breve descrição de sua função, permitindo que você integre nossa API em sua aplicação com facilidade.:

## Endpoints Disponíveis

#### 1. Listar Usuários

* **Método:** <span class="APIMethod APIMethod_fixedWidth APIMethod_get" data-testid="http-method">GET</span>
* **Endpoint:`/users`**
* **Descrição:** Lista todos os usuários criados, fornecendo detalhes básicos de cada usuário.
* **URL:** [Página de Referência](/v3.0/reference/api-listar-usuarios).

#### 2. Criar Usuário:

* **Método:** <span class="APIMethod APIMethod_fixedWidth APIMethod_post" data-testid="http-method">POST</span>
* **Endpoint:`/users`**
* **Descrição:** Cadastra um usuário para que possa realizar login via SSO.
* **URL:** [Página de Referência](/v3.0/reference/api-criar-usuario).

#### 2. Detalhes do Usuário:

* **Método:** <span class="APIMethod APIMethod_fixedWidth APIMethod_get" data-testid="http-method">GET</span>
* **Endpoint:`/users/{id}`**
* **Descrição:** Lista os detalhes de um usuário
* **URL:** [Página de Referência](/v3.0/reference/api-detalhes-usuario).
