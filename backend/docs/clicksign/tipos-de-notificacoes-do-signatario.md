# Tipos de notificações para os signatários

Introdução às notificações

Nesta página, você verá como notificar os signatários de um envelope na Clicksign API. A notificação de signatários é uma etapa importante no processo de assinatura eletrônica, pois informa aos destinatários que há documentos a serem assinados e fornece detalhes sobre como acessá-los.

# Tipos de notificação

Existem diferentes tipos de notificações que podem ser enviadas aos signatários, cada uma com sua finalidade específica:

* **Solicitação de assinatura:** Informa aos signatários que há documentos a serem assinados e fornece um link para acessá-los.
* **Lembrete de solicitação de assinatura:** Enviado como um lembrete aos signatários que ainda não assinaram os documentos dentro do prazo especificado.
* **Documento assinado:** Notifica os signatários quando todos os documentos foram assinados com sucesso e disponibiliza-o para download.
