# 2.2. Requisitos

# O que são requisitos?

São critérios necessários para que os documentos sejam assinados pelos signatários na plataforma Clicksign, garantindo segurança, conformidade e eficiência no processo de assinatura eletrônica.

# Regra para ativação do envelope

Para ativar um envelope na plataforma Clicksign, é imprescindível que todos os documentos e signatários atendam aos seguintes requisitos:

* **Autenticação:** Cada signatário deve possuir pelo menos um critério de autenticação configurado.
* **Qualificação:** Cada documento deve atender pelo menos um critério de qualificação.

Essas regras garantem que o processo de assinatura seja realizado com segurança e de acordo com os padrões exigidos.

# Requisitos de qualificação

Os requisitos de qualificação são critérios adicionais que determinam as condições necessárias para a validade e conformidade das assinaturas. Cada documento deve atender pelo menos uma qualificação por signatário:

* **Testemunhas:** É possível adicionar uma ou mais testemunhas para validar legalmente as assinaturas realizadas em determinados documentos.
* **Parte:** O signatário é identificado como uma parte interessada ou envolvida diretamente no documento, como autor ou destinatário.

É permitido adicionar diversas qualificações para um mesmo signatário. No momento da assinatura, ele precisará concordar com todas de uma única vez.

Veja todas as qualificações disponíveis [clicando aqui](/v3.0/docs/adicionar-requisito-de-qualificacao).

# Requisitos de autenticação

A autenticação é fundamental para garantir a segurança e a identidade dos signatários. Cada signatário deve atender a pelo menos um dos critérios de autenticação disponíveis:

* **Código de Verificação:** Um código único é enviado ao e-mail ou número de telefone do signatário para autenticar sua identidade.

# Requisitos de rubrica (opcional)

Embora não sejam obrigatórios, os requisitos de rubrica podem ser aplicados para reforçar a autenticação e a validade do documento final. Entre as opções disponíveis, destacam-se:

* **Rubrica Iniciais:** Permite que o signatário insira suas iniciais de forma eletrônica no documento, assegurando conformidade com o conteúdo assinado.
* **Rubrica Manuscrita:** O signatário utiliza o mouse, touchpad ou tela sensível ao toque para desenhar sua rubrica manuscrita diretamente no documento.

Esses requisitos são particularmente úteis em documentos que demandam evidências adicionais de assinatura.
