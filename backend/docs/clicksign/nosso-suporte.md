# Suporte da Clicksign

Nossa equipe de suporte técnico está pronta para ajudar com dúvidas sobre a API ClickSign.

📧 [Formulário para contato com o Suporte](https://www.clicksign.com/suporte)

💡 Para respostas mais rápidas, inclua estas informações no seu e-mail:

```Text Exemplo de Corpo do E-mail
Ambiente: sandbox ou produção
Conta: 123456

Método e Path da requisição: POST /api/v3/envelopes
Status code do erro: 442
Body JSON enviado:
{}

Body JSON recebido:
{}
```

## O que nosso suporte pode ajudar:

Por motivos de segurança, bem como particularidades das linguagens e sistemas escolhidos por cada desenvolvedor, o atendimento do Suporte da Clicksign é direcionado a dúvidas relacionadas à arquitetura da API e suas regras de negócio. Não analisamos código fonte das aplicações.
