# Eventos

Explore Nossos Endpoints: Eventos de Documento e Envelope

**Bem-vindo à página de referência dos endpoints de eventos de documento e envelope da Clicksign!**

Aqui você encontrará informações sobre como acessar e utilizar nossos endpoints para consultar eventos relacionados a documentos.

## Endpoints Disponíveis:

#### 1. Consultar Eventos de um Documento:

* **Método:** <span class="APIMethod APIMethod_fixedWidth APIMethod_get " data-testid="http-method">GET</span>
* **Endpoint:** `/envelopes/`{`envelope_id`}`/documents/`{`document_id`}`/events`
* **Descrição:** Lista os eventos associados a um documento específico.
* **URL:** [Página de Referência](https://developers.clicksign.com/v3.0/reference/eventos-de-um-documento).
