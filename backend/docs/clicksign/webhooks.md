# Webhooks

Explore Nossos Endpoints: CRUD de Webhooks

Aqui, você encontrará uma lista completa de endpoints para gerenciar webhooks em nossa API. Cada endpoint vem com uma breve descrição de sua função, facilitando sua integração em sua aplicação.

## Endpoints Disponíveis:

#### 1. Consultar Webhooks:

* **Método:** <span class="APIMethod APIMethod_fixedWidth APIMethod_get" data-testid="http-method">GET</span>
* **Endpoint:** **`/webhooks`**
* **Descrição:** Lista os Webhooks configurados.
* **URL:** [Página de Referência](/v3.0/reference/api-listar-webhooks).

#### 2. Criar Webhook:

* **Método:** <span class="APIMethod APIMethod_fixedWidth APIMethod_post" data-testid="http-method">POST</span>
* **Endpoint:** **`/webhooks`**
* **Descrição:** Adiciona um novo webhooks.
* **URL:** [Página de Referência](/v3.0/reference/api-criar-webhook).

#### 3. Visualizar Webhook:

* **Método:** <span class="APIMethod APIMethod_fixedWidth APIMethod_get " data-testid="http-method">GET</span>
* **Endpoint:`/webhooks/{webhook_id}`**
* **Descrição:** Recupera os detalhes de um webhooks específico com base no ID fornecido.
* **URL:** [Página de Referência](/v3.0/reference/api-detalhes-do-webhook).

#### 4. Editar Webhook:

* **Método:** <span class="APIMethod APIMethod_fixedWidth APIMethod_patch" data-testid="http-method">PATCH</span>
* **Endpoint:`/webhooks/{webhook_id}`**
* **Descrição:** Editar um webhook.
* **URL:** [Página de Referência](/v3.0/reference/api-editar-webhook).

#### 4. Excluir um Webhook:

* **Método:** <span class="APIMethod APIMethod_fixedWidth APIMethod_delete" data-testid="http-method">DELETE</span>
* **Endpoint:`/webhooks/{webhook_id}`**
* **Descrição:** Excluir definitivamente um webhook.
* **URL:** [Página de Referência](/v3.0/reference/api-excluir-webhook).
