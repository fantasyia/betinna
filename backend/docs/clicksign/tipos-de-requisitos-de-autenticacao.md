# Tipos de requisitos de autenticação

Nesta página, você encontrará informações detalhadas sobre as diferentes formas de autenticação disponíveis na plataforma Clicksign. A autenticação é uma etapa crucial no processo de assinatura eletrônica, pois garante a identidade do signatário e a segurança da transação.

## Por que a autenticação é importante?

A autenticação garante que a pessoa que está assinando o documento é realmente quem ela diz ser. Isso previne fraudes e garante a validade legal do documento.

## Métodos de autenticação

A plataforma Clicksign oferece uma variedade de métodos de autenticação para atender às suas necessidades. Você pode escolher o método mais adequado para cada signatário e situação.

1. **Token:**

* **Código de verificação:** Um código único é enviado para o email ou celular do signatário. O signatário precisa inserir esse código para confirmar sua identidade.
* **Código de verificação presencial**: Para processos de Assinatura Presencial, o anfitrião (operador) pode receber o token de acesso, QR Code ou link. Este recurso permite iniciar o processo de assinatura mesmo que o signatário não possua um dispositivo, email ou telefone. Saiba mais na página de <Anchor label="Assinatura Presencial" target="_blank" href="/docs/introducao-a-assinatura-presencial">Assinatura Presencial</Anchor>

2. **Coleta de evidências:**

* **Foto:** O signatário tira uma foto de si mesmo usando a câmera do dispositivo. Essa foto é utilizada para comparar com a foto do documento de identidade, se fornecido.
* **Imagem:** O signatário pode enviar uma imagem de um documento de identidade, como RG ou CNH, para comprovar sua identidade.
* **Outros:** A plataforma Clicksign permite a integração com outras ferramentas de autenticação, como biometria e reconhecimento facial.

3. **Autenticação avançada:**

* **Certificado Digital:** O signatário utiliza um certificado digital para assinar o documento. Essa opção oferece o mais alto nível de segurança e é ideal para documentos que exigem maior garantia de autenticidade.

## Escolhendo o método de autenticação

Ao escolher o método de autenticação, leve em consideração os seguintes fatores:

**Nível de segurança:** Qual o nível de segurança necessário para o documento?
**Conveniência:** Qual método é mais conveniente para o signatário?
**Custo:** Alguns métodos de autenticação podem ter custos adicionais.
**Regulamentações:** Verifique se existem regulamentações específicas que exigem o uso de um determinado método de autenticação.

## Flexibilidade e personalização

A plataforma Clicksign permite que você personalize os métodos de autenticação para cada signatário e documento. Você pode combinar diferentes métodos para criar um processo de assinatura seguro e eficiente.

## Conheça as autenticações possíveis

Para facilitar a sua escolha e garantir que você tenha acesso a todas as opções disponíveis, listamos abaixo todos os métodos de autenticação que a plataforma Clicksign oferece:

| Token       | email                | Define o envio de token por e-mail.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Token       | sms                  | Define o envio de token por SMS.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

| Assinatura  | handwritten          | Define a solicitação de assinatura manuscrita como ponto de autenticação no momento da assinatura.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Imagem      | address\_proof       | Define o comprovante de endereço como autenticação.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Imagem      | liveness             | Define a solicitação de selfie dinâmica como ponto de autenticação adicional para o signatário.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Imagem      | official\_document   | Define a solicitação da foto (frente e verso) do documento oficial como ponto de autenticação do signatário no momento da assinatura.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Imagem      | selfie               | Define a solicitação de selfie como ponto de autenticação ao signatário no momento da assinatura, utilizando a câmera do dispositivo. Algumas incompatibilidades podem ocorrer como: caso o navegador não tenha suporte ao plugin; dispositivo não possua câmera instalada corretamente ou usuário tenha bloqueado acesso à câmera.                                                                                                                                                                                                                                                                                               |
| Imagem      | facial\_biometrics   | Define a solicitação de biometria facial como ponto de autenticação adicional para o signatário. Quando esta autenticação está habilitada para um signatário, as autenticações `official_document_enabled`, `liveness_enabled` e `selfie_enabled`, não são permitidas.                                                                                                                                                                                                                                                                                                                                                            |
| Imagem      | biometric            | Define solicitação de biometria SERPRO como ponto de autenticação adicional para o signatário. Essa abordagem garante maior segurança e agilidade no processo de verificação de identidade. Quando esta autenticação está habilitada para um signatário, o CPF é um dado obrigatório e as autenticações `official_document_enabled,liveness_enabled` e `selfie_enabled`, não são permitidas.                                                             |
| Imagem      | identity\_biometrics | Define a Biometria (Base Ampliada) como uma etapa de autenticação para o signatário. Nesse modelo, não é necessário o envio de um documento com foto, pois a validação da identidade é realizada por meio da comparação facial com uma base biométrica confiável. Essa abordagem proporciona maior segurança e agilidade ao processo de verificação de identidade. Quando essa autenticação estiver habilitada para um signatário, o preenchimento do CPF será obrigatório. Além disso, as autenticações `biometric`, `facial_biometrics`, `official_document`, `liveness` e `selfie` não poderão ser utilizadas simultaneamente. |

| Imagem      | documentscopy        | Define a solicitação de documentoscopia como ponto de autenticação do signatário, este item valida apenas a integridade do documento, alem de extração via ocr dos dados do documento e comparado aos dados informados.                                                                                                                                                                                                                                                                                                                                                                                                           |

| Assinatura  | presential           | Define a ocorrência da assinatura em modo presencial. Com signatário e anfitrião no mesmo local fisíco.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

O signatário assina diretamente no widget integrado à aplicação externa, fornecendo apenas dados federais (nome, CPF, data de nascimento) e localização Ideal para assinaturas em ambiente controlado ou presencial.                                                                                                                                                                                                                                                                                                                    |

> 🚧 Importante
>
> * A autenticação `facial_biometric` possui um custo de R$ 1,50 por biometria facial realizada com sucesso, sendo o resultado do reconhecimento facial positivo ou negativo. A cobrança não será gerada apenas nos casos em que o sistema estiver inoperante ou retornar um erro inesperado.
> * A autenticação `biometric` possui um custo de R$ 4,50 por consulta realizada com sucesso à base de dados da SERPRO, sendo o resultado do reconhecimento facial positivo ou negativo. A cobrança não será gerada apenas nos casos em que o sistema estiver inoperante ou retornar um erro inesperado.
> * A autenticação `documentscopy`possui um custo de R$ 4,50 por solicitação realizada, sendo o resultado a validação ou invalidação do documento enviado.  A cobrança não será gerada apenas nos casos em que o sistema estiver inoperante.
