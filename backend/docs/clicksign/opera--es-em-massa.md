# Operações de Requisitos em Massa

Endpoint para realização de criação ou exclusão de requisitos em massa.

**Bem-vindo à Página de Criação de Requisitos em Massa da Clicksign!**

Estamos muito felizes em vê-lo por aqui! Nesta seção, você tem a oportunidade de definir requisitos específicos para seus documentos e signatários em nossa API de assinatura eletrônica. Através desse endpoint é possível enviar várias operações em uma só requisição, isso é possível pois usamos extensão [ATOMIC OPERATIONS](https://jsonapi.org/ext/atomic/) do JSON API.

## Endpoints Disponíveis:

#### 1. Criar Requisitos:

* **Método:** <span class="APIMethod APIMethod_fixedWidth APIMethod_post" data-testid="http-method">POST</span>
* **Endpoint:** **`/envelopes/{envelope_id}/bulk_requirements`**
* **Descrição:** Cria ou remover requisitos de assinatura.
* **URL:** [Página de Referência](/v3.0/reference/bulk-requirements).
