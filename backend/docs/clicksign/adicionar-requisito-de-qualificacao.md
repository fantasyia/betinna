# Tipos de requisitos de qualificação

Nesta página, você encontrará uma visão detalhada sobre os critérios de qualificação que podem ser aplicados aos documentos na plataforma Clicksign. As qualificações são requisitos adicionais que determinam as condições necessárias para a validade e conformidade das assinaturas eletrônicas.

## Requisitos de qualificação

É importante entender a diferença entre esses dois conceitos:

**Requisitos de qualificação:** São critérios que devem ser preenchidos para que uma qualificação seja atribuída a um signatário em um documento. Eles garantem a validade e a aplicabilidade da qualificação. **Qualificações:** São atributos que podem ser adicionados aos signatários para especificar o seu papel ou função no documento, como "Testemunha" ou "Parte".
